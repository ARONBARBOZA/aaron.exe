Drop your photos in this folder with these exact filenames:

- hero-light.jpg — portrait shown in light mode
- hero-dark.jpg  — portrait shown in dark mode
                   (can be the same photo twice, or two different shots —
                   e.g. a brighter one for light mode and a moodier
                   black-and-white one for dark mode)
- travel.jpg     — first polaroid on the Work tab
- music.jpg      — second polaroid — links out to your Spotify playlist
                   when clicked (update the URL in index.html, search for
                   "YOUR_PLAYLIST_ID")
- cat.jpg        — third polaroid

A 4:5 vertical portrait works best for the hero photos — they're
auto-cropped into a circle, no manual cropping needed.

Any image works — the site auto-crops to fit. If a file is missing,
the site just shows a small placeholder in its place instead of breaking.
